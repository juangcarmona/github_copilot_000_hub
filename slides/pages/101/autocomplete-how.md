# How Autocomplete Works

Copilot watches you type and predicts what comes next.

<div class="grid grid-cols-2 gap-8 mt-4">

<div>

### What triggers suggestions

- You start typing a function body
- You write a comment describing intent
- You define a variable name that implies a pattern
- You're in a repetitive structure

</div>

<div>

### Keyboard shortcuts

| Key | Action |
|-----|--------|
| <kbd>Tab</kbd> | Accept full suggestion |
| <kbd>Ctrl+→</kbd> | Accept word-by-word |
| <kbd>Esc</kbd> | Dismiss |
| Hover | See alternative suggestions |

</div>

</div>

<div class="mt-6 text-sm opacity-70">

This is **completion**, not comprehension. Great for boilerplate. Doesn't understand your business logic.

</div>
