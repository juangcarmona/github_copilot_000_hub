# Trust, Security & Privacy

::left::

## Security

- Data encrypted in transit and at rest
- AI-based vulnerability prevention filters
- Blocks insecure patterns (SQL injection, path injection)
- Optional public code matching filter

## Privacy

- Your code is **never used to train** Copilot models
- Prompts are processed and deleted after inference
- Enterprise plans include additional governance controls

::right::

## Data Processed

| Data Type | Description |
|---|---|
| Prompts | Code + context sent to generate suggestions |
| Suggestions | AI-generated code responses |
| Feedback | Thumbs up/down, optional comments |
| Engagement | Pseudonymous interaction metrics |
