# What Drives Cost

### Cost grows with context, iterations, and model choice.

::left::

## Token Consumption

- **Context** → input tokens
- **Output** → generated tokens
- **Iteration** → execution loops
- **Model tier** → price per token

::right::

## Model Tiers

- Lightweight → low
- Coding → medium
- Reasoning → high
