# Chat Surfaces

<div class="grid grid-cols-2 gap-6">

<div class="leading-snug">

Three ways to talk to Copilot - each for a different workflow.

### Chat View <kbd>Ctrl+Alt+I</kbd>
Full conversation panel. Multi-turn, multi-file. Best for exploration and complex tasks.

### Inline Chat <kbd>Ctrl+I</kbd>
Opens in the editor. Scoped to visible code. Best for quick, targeted edits.

### Quick Chat <kbd>Ctrl+Shift+Alt+L</kbd>
Lightweight popup. One-shot questions. No session history.
