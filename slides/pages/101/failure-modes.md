# Beginner Failure Modes (1/2)

### ❌ The Vague Prompt
`"fix this"` / `"make it better"` — no direction, random results.

**Fix:** Be specific about what, where, and how.

### ❌ The Mega-File
Working in a 2000-line file with everything mixed together.

**Fix:** Keep files focused. Open only relevant tabs.

### ❌ The Blind Accept
Accepting every suggestion without reading it.

**Fix:** Read before you Tab. Treat suggestions as drafts.
