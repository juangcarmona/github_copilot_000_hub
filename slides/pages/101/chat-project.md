# Exploring a Codebase with Chat

### Discover & Analyze

- `"what are the main modules and how do they relate?"`
- `"where is authentication handled?"`
- `"summarize what changed in the last 10 commits"`
- `"explain the state transitions in this file"`
- `"how does the payment flow reach the database?"`

### Document

- `"write a README section for this module"`
- `"generate an architecture overview"`
- `"add JSDoc comments to this file"`

<div class="mt-4 text-sm opacity-70">

Start wide (`#codebase`), then narrow (`#file`). Use `#git` to understand *why* code exists.

</div>
