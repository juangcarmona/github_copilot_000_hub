# Probabilistic, Not Deterministic

Copilot predicts the most likely next tokens — not the "correct" answer.

<div class="grid grid-cols-2 gap-8 mt-4">

<div>

### What this means

- Same prompt → **different results** each time
- Suggestions are likely, not guaranteed correct
- Confidence ≠ correctness

</div>

<div>

### What to do about it

- **Run it twice** — try again if the first result is bad
- **Rephrase** — different wording, different patterns
- **Verify** — don't debug confidence, test the output

</div>

</div>

<div class="mt-6 p-3 bg-yellow-50 border border-yellow-200 rounded text-sm">

💡 **Analogy:** Copilot is like a well-read junior developer who writes fluently but sometimes misremembers details. It needs code review, not blind trust.

</div>
