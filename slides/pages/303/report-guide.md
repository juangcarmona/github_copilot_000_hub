# Reading Usage Data

<div class="text-sm">

| Signal | What It Tells You | Worth Exploring |
|---|---|---|
| **Total requests** | Interactive Copilot usage | Low usage → adoption opportunity |
| **Frontier %** | Premium reasoning model use | High % → model optimization |
| **% Auto** | Requests via Auto mode | Low % → manual selection habits |
| **AI usage level** | Relative usage across org | Low usage → worth a conversation |
| **Billed requests** | Beyond included quota | Heavy premium model usage |

</div>
