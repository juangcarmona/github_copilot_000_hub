# Prompt Files — Best Practices

- `State the goal clearly` Define the expected output format explicitly
- `Include examples` Short input/output samples improve accuracy
- `Link, don't duplicate` Reference instruction files instead of copying content
- `Use variables` `${selection}` and `${input:...}` make prompts dynamic
- `Test interactively` Use the editor Play button to iterate quickly
- `Share with the team` Commit prompt files to the repository for consistency
