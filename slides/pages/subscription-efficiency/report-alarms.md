# When to Have a Conversation

::before::

- **Low usage** — team member barely using interactive Copilot
- **Low frontier + low Auto** — always picking lightweight models manually
- **Very high frontier usage** — premium models for everything, consuming shared credits quickly

::after::

- Start with curiosity — understand the context first
- *"What tasks are you using Copilot for most?"*
- Suggest **Auto mode** as the default choice
- Reserve reasoning models for architecture, hard debugging, and large refactors
- Lightweight models for quick edits and boilerplate
