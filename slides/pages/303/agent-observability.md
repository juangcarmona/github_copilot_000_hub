# Agent Observability

<div class="grid grid-cols-2 gap-6 mt-4">
<div class="leading-snug">

Every agent session produces an audit trail.

**What's visible:**
- Model invocations per session
- Tools called and their results
- Files read, edited, created
- Terminal commands executed
- Total token consumption

**Operational use:**
- Debug unexpected agent behavior
- Audit changes before merge
- Identify workflow inefficiencies
- Verify instruction file effectiveness
