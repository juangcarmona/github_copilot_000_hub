# Same AI, Different Surfaces

::left::

## IDE Integration
**VS Code** — most complete experience: autocomplete, chat, agent mode, MCP, full extension ecosystem.

**Visual Studio** — strong .NET integration; autocomplete + chat + agent; deep solution awareness.

**JetBrains Suite** — full support across IntelliJ, Rider, PyCharm; autocomplete + chat + agent.

::right::

## Beyond the IDE

**CLI** — `gh copilot suggest` / `gh copilot explain`. Terminal-native workflows, CI scripting.

**GitHub.com** — PR summaries, code review, issue triage directly in the browser.

**Agent / Harness mode** — Copilot operates autonomously; triggered from issues or assigned tasks; no active IDE session required.

<div class="mt-4 text-sm opacity-70">

The AI capabilities are the same across surfaces. The ergonomics, workflow depth, and integration points differ.

</div>
