# Instruction Drift

::left::

## How Drift Happens

1. Instructions match the codebase

2. The stack evolves
   - new framework
   - new conventions
   - new architecture

3. Instructions are not updated

4. Copilot keeps generating outdated patterns

<div class="mt-4 p-3 bg-red-50 border-l-4 border-red-500 text-sm">

Outdated instructions create confidently wrong code.

</div>

::right::

## Preventing Drift

**Review instructions when:**
- frameworks change
- architecture changes
- patterns evolve
- Copilot suggests outdated code

## Quick Checklist

- Instructions still match the repo?
- Scoped files still apply correctly?
- No conflicting rules?
- Deprecated patterns removed?
