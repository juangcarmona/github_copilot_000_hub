# Inline Chat: Edit in Place

<div class="grid grid-cols-2 gap-6">

<div class="leading-snug">

Select code → <kbd>Ctrl+I</kbd> → describe → review diff.

**When to use it:**
- Refactoring a specific function
- Adding error handling to a block
- Translating code between languages
- Fixing a bug you can see

**Flow:**
1. Your selection becomes the context
2. Describe the change in natural language
3. Copilot shows a diff inline
4. Accept (**Keep**) or reject (**Undo**)

</div>
