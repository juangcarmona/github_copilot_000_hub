# Individual Speed Is Not Organizational Velocity

::left::

## Visible Gains

- More code written
- Faster drafts
- More PRs opened
- More tickets marked done

::right::

## System Risks

- Shallower review depth
- Architectural drift
- Hidden rework cycles
- Silent quality degradation
