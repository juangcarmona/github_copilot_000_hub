# Plan → Delegate → Review

::left::

## Plan Agent Workflow

**1. Describe the task** — high-level requirements, constraints, scope.

**2. Plan agent asks questions** — clarifies ambiguity before committing to a strategy.

**3. Review the plan** — approve, adjust, or reject before any code is written.

**4. Hand off to execution** — delegate to:
- Local Agent (interactive)
- Copilot CLI (background, isolated)
- Cloud Agent (async, PR-based)

::right::

## Why Plan First?

- Catch misunderstandings **before** implementation
- Control scope and approach **before** burning tokens
- Create a reviewable artifact
- Enable safe delegation to autonomous surfaces

<div class="mt-4 text-sm opacity-70">

Plan mode separates **thinking** from **doing**. The plan becomes the contract between you and the agent.

</div>
