# When to Act on Usage Data

<div class="text-sm">

| Pattern | Likely Cause | Action |
|---|---|---|
| Very high frontier % | Premium models for everything | Coach toward Auto mode |
| Unusual spikes | Agent workflows on large PRs | Review workflow design |
| Low usage across team | Adoption friction | Investigate onboarding gaps |
| Zero Auto mode usage | Manual model selection habit | Suggest Auto as default |
| Budget approaching cap | Uncontrolled agent sessions | Set per-user guardrails |

</div>

<div class="mt-6 p-4 rounded-lg bg-blue-50 border border-blue-200">

**The conversation starts with curiosity, not judgment.**

*"What kind of work drove this pattern?"* — not *"Why did you use so many credits?"*

Usage data is operational intelligence for teams, not surveillance for managers.

</div>
