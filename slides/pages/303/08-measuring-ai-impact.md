# Measuring AI Impact

<div class="grid grid-cols-2 gap-6 mt-4">
<div>

### ✅ Measure Outcomes

| Metric | What It Shows |
|---|---|
| Cycle time (commit → prod) | Delivery speed |
| PR review turnaround | Review efficiency |
| Bug escape rate | Quality |
| Rework after merge | Implementation quality |
| Developer satisfaction | Perceived value |

<p class="mt-3 text-sm font-semibold text-green-700">Capture baselines before expanding AI access.</p>

</div>
<div>

### ❌ Don't Measure Only Activity

| Metric | Why It Misleads |
|---|---|
| Lines of code | More ≠ better |
| PRs opened | Volume ≠ value |
| Tickets closed | Speed ≠ quality |
| AI request count | Usage ≠ impact |
| Adoption % | Seats ≠ outcomes |

<p class="mt-3 text-sm font-semibold text-red-600">High activity + degrading quality = failure mode.</p>

</div>
</div>
