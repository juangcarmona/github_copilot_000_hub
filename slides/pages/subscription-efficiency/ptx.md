# PTX: Plan → Then → Execute

### Good planning reduces retries, rework, and uncontrolled execution.

::left::

## Planning Phase

### Explore
- Reason about architecture and trade-offs
- Use **approved AI tools** for exploration

### Define
- Clarify goals, constraints, and scope
- Design the execution approach before coding

::right::

## Execution Phase

| Planner | Executor |
|---|---|
| Define execution steps | Implement incrementally |
| Bound scope and context | Validate outputs continuously |
| Select the appropriate workflow | Avoid uncontrolled iteration |
