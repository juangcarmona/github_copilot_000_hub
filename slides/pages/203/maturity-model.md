# AI-Ready Repository Maturity Model

| Level | What You Have | What You Get |
|---|---|---|
| **0 - Baseline** | Clean code, good naming, type annotations | Reasonable autocomplete, generic Chat responses |
| **1 - Instructed** | `README.md` + `.github/copilot-instructions.md` | Consistent conventions, stack-aware suggestions |
| **2 - Layered** | Path-specific instructions + prompt files | Domain-aware generation, one-command workflows |
| **3 - Agentic** | Agent profiles + ADRs + specs in `docs/` | Autonomous task execution with project context |
| **4 - Integrated** | CI quality gates + living docs + automated reviews | AI operates as a continuous engineering collaborator |

<div class="mt-6 text-sm opacity-70">

Start at Level 1. Most teams see measurable improvement within a day. Levels 2–4 are compounding investments.

</div>
