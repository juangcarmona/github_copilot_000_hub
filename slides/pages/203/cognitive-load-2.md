# Repository Cognitive Load (2/2)

## Reducing Load = Better AI

<div class="text-sm">

| Technique | Human Benefit | AI Benefit |
|---|---|---|
| Flat folder structure | Easier scanning | Faster file discovery |
| One concept per file | Focused reading | Precise embeddings |
| Explicit naming | Self-documenting | Better retrieval |
| README per module | Onboarding speed | Context for agents |
| Consistent patterns | Predictable code | Pattern replication |

</div>

<div class="mt-6">

The same principles that reduce cognitive load for developers also reduce ambiguity for AI systems.

A repo that is hard for a new developer to understand is equally hard for Copilot to reason about.

</div>
