# Keep History Relevant

- `Use threads` Start a new conversation for each distinct task
- `Delete irrelevant messages` Remove old or failed prompts that no longer apply
- `Focus on current goal` Ensure history supports the immediate request
- `Start fresh when stuck` /clear resets the conversation context
