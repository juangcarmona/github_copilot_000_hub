# Agents Window: Operational View

<div class="grid grid-cols-2 gap-6 mt-4">
<div class="leading-snug">

The Agents window gives engineering leads visibility into active work.

**Session management:**
- Multiple sessions across projects
- Track progress in real time
- Review agent decisions before merge
- Switch between code-first and agent-first

**Team patterns:**
- Which tasks are delegated to agents?
- How long do sessions run?
- What's the review overhead?
- Are agents hitting dead ends?
