# Baseline Before Scale

<div class="mt-2 text-base opacity-80">
Without a baseline, AI impact measurement becomes storytelling.
</div>

<div class="grid grid-cols-2 gap-6 mt-4 text-sm">
<div>

## Measure These

- Cycle time from first commit to production
- PR review turnaround time
- Bug escape rate to production
- Test coverage by module or service
- Developer satisfaction / perceived productivity

Capture these *before* expanding AI access - or at the start of a structured rollout phase.

</div>
<div>

## Do Not Measure Only

- Lines of code
- Number of PRs opened
- Tickets closed
- Raw Copilot request count
- AI usage ranking per developer

These signal activity, not outcomes.
High activity with degrading quality is a failure mode.

</div>
