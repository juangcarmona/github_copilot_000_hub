# AI-Ready Repository Maturity Model

| Level | Description |
|---|---|
| **0 - Baseline** | Clean code, consistent naming, basic types |
| **1 - Documented** | README and ARCHITECTURE.md present; decisions recorded |
| **2 - Structured** | Focused modules, ADRs, and specs in `docs/` |
| **3 - Maintained** | Architecture checks and naming audits prevent drift |

Start with documentation and focused files; each step increases predictability for humans and AI.
