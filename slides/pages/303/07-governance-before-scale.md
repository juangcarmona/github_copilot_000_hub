# Governance Before Scale

<div class="grid grid-cols-3 gap-4 mt-6">

<div class="rounded-xl border border-red-200 p-4 bg-red-50 text-sm">
<h2 class="font-bold mb-2">❌ Governance After Scale</h2>

- Shadow AI usage established
- Costs already spiking
- Inconsistent practices hardened
- Reactive controls → disruption
- "We tried AI, it didn't work"
</div>

<div class="rounded-xl border border-yellow-200 p-4 bg-yellow-50 text-sm">
<h2 class="font-bold mb-2">⚠️ Over-Governance</h2>

- Policies block adoption
- Developers bypass approved tools
- Innovation stalls
- AI value unrealized
- "We have AI, nobody uses it"
</div>

<div class="rounded-xl border border-green-200 p-4 bg-green-50 text-sm">
<h2 class="font-bold mb-2">✅ Right-Sized Governance</h2>

- Data policy from day one
- Lightweight guardrails that evolve
- Centralize policy, decentralize execution
- Visibility before enforcement
- "AI is part of how we work"
</div>

</div>

<div class="mt-6 text-center text-sm">

**Centralize:** data policy, approved tools, quality gates, budget caps.
**Decentralize:** instruction files, workflow design, agent configuration, model selection.

</div>

<div class="mt-3 p-3 rounded-lg bg-blue-50 border border-blue-200 text-sm text-center">
