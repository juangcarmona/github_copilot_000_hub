# Combine Copilot with Other AI Tools

::left::

## Think outside the IDE

- ⚠️ Never share confidential or client data with external tools
- Explore architecture with ChatGPT, or local models
- M365 Copilot is organization-approved
- Reason about trade-offs before touching code
- Prototype ideas and refine constraints
- Zero PRU cost during the thinking phase

::right::

## Implement inside the IDE

- Copilot Business is approved for corporate & client code
- Move to Copilot Agent with a clear plan
- Execute directly in the repository
- Let autocomplete handle the routine parts
